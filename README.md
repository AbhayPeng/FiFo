# Synchronous FIFO using Verilog

Project Overview
Designed and implemented a synchronous FIFO (First-In, First-Out) buffer using Verilog HDL in AMD Xilinx Vivado. The design stores and retrieves 8-bit data in sequential order using a common clock.

Features
- 8 entries, each 8 bits wide.
- Synchronous active-high reset.
- Independent read and write pointers.
- FIFO status flags: `full` and `empty`.
- Data storage and retrieval in FIFO order.
- Testbench verification of reset, read/write operations, and full/empty conditions.

Tools & Technologies
- **HDL:** Verilog
- **EDA Tool:** AMD Xilinx Vivado
- **Verification:** Behavioral Simulation

Key Learnings
Gained practical experience in RTL design, sequential logic, pointer management, status-flag generation, FIFO operation, and simulation-based functional verification.
